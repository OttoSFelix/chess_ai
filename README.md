# chess_ai
An ai algorithm to play chess with.


## Running the local ai platform

### Setup
- Make sure you have python (3.10 or newer), node.js and poetry installed
- Clone the repository and move to project directory
- Run the automatic configuration script [config.sh](./config.sh)
### Running the platform
- Move to [tira-ai-local/app](tira-ai-local/app) and run `npm start`
- Inside the application window under "Submit AI" paste or drag the path to the chess_ai project, check "Run setup" and press "Submit"
